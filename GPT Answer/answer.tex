\section{Explanation of the SU(2) Global Anomaly Remark}

We explain the logic of the remark step by step.

\subsection{SU(2) Gauge Theory in Four Dimensions}

The weak interaction is described by an $SU(2)$ gauge theory. Therefore, on our
four-dimensional spacetime $M$ there is an $SU(2)$ principal bundle
\[
P \to M.
\]
On a local patch we may treat spacetime as $\mathbb{R}^4$, and a gauge
transformation is a map
\[
g : \mathbb{R}^4 \to SU(2).
\]

\subsection{Compactification to $S^4$ and Large Gauge Transformations}

Assume the gauge transformation becomes trivial at spatial infinity:
\[
g(x) \to \mathbf{1} \quad \text{as } |x|\to\infty.
\]
This allows us to compactify $\mathbb{R}^4$ by adding a point at infinity:
\[
\mathbb{R}^4 \cup \{\infty\} \cong S^4,
\]
with $g(\infty)=\mathbf{1}$. Hence gauge transformations are classified by maps
\[
g : S^4 \to SU(2) \simeq S^3.
\]
The homotopy classes of such maps are elements of
\[
\pi_4(S^3)\simeq\mathbb{Z}_2=\{0,1\}.
\]
The nontrivial class ($1$) corresponds to a ``large'' gauge transformation.

\subsection{SU(2) Doublet Fermions}

Fermions charged under the weak force transform in the fundamental (doublet)
representation $\mathbf{2}$ of $SU(2)$. A single such fermion field is a section of 
the associated vector bundle
\[
\mathbf{2}\otimes S \longrightarrow M,
\]
where $S$ is the spinor bundle. For our purposes, the only important fact is:

\medskip
\centerline{\textbf{A single SU(2) doublet fermion is one section of a vector bundle.}}
\medskip

\subsection{Witten's SU(2) Global Anomaly}

A key result of Witten (1982) states that under a large gauge transformation
$g:S^4\to S^3$, the partition function of a single $SU(2)$ doublet fermion transforms as
\[
Z_{\text{single doublet}} \;\longrightarrow\; (-1)^s\, Z_{\text{single doublet}},
\]
where $s=[g]\in \pi_4(S^3)\simeq\mathbb{Z}_2$. Thus
\[
s=0:\; Z \text{ invariant},\qquad 
s=1:\; Z\mapsto -Z.
\]
Therefore:

\medskip
\centerline{\textbf{A single SU(2) doublet suffers from a global SU(2) anomaly.}}
\medskip

\subsection{Multiple Doublets and Anomaly Cancellation}

If there are $N$ doublets, the total transformation is
\[
Z \longrightarrow (-1)^{Ns} Z.
\]
The theory is gauge invariant for all gauge transformations if and only if $N$ is even.
In the Standard Model, one generation contains
\[
3 \text{ quark doublets } + 1 \text{ lepton doublet } = 4 \text{ doublets}.
\]
Hence
\[
(-1)^{4s} = +1,
\]
and the anomaly cancels.

This explains, for instance, why one cannot simply change $SU(3)$ color to $SU(4)$:
it would change the number of weak doublets, potentially making $N$ odd and producing
an inconsistency.

\subsection{Summary}

\begin{itemize}
    \item Large $SU(2)$ gauge transformations are classified by $\pi_4(S^3)\simeq\mathbb{Z}_2$.
    \item A single doublet fermion changes sign under the nontrivial transformation.
    \item A consistent theory must have an \emph{even} number of doublets.
    \item The Standard Model satisfies this automatically ($N=4$ per generation).
\end{itemize}

\section{Fiber Choice in the Covering Map $\mathbb{R}\to S^1$}

Consider the covering map
\[
p:\mathbb{R}\longrightarrow S^1,\qquad p(x)=e^{2\pi i x}.
\]
For any point $z=e^{2\pi i\alpha}\in S^1$, the fiber is
\[
p^{-1}(z)=\{x\in\mathbb{R}\mid e^{2\pi i x}=z\}=\alpha+\mathbb{Z},
\]
a translated copy of $\mathbb{Z}$.  
Thus every fiber is homeomorphic to the discrete set $\mathbb{Z}$.

In the long exact sequence of a fibration, one chooses a basepoint $b_0\in S^1$
and defines the fiber as $p^{-1}(b_0)$.  
Although $b_0=1\in S^1$ (the identity element) is the conventional choice,
any $b_0$ works because $S^1$ is path-connected and homotopy groups based
at different points are naturally isomorphic.

\section{Homotopy Groups of the Discrete Space $\mathbb{Z}$}

Although $\mathbb{Z}$ is not a manifold, it is a valid topological space
and its homotopy groups are well-defined.

\subsection{All Continuous Maps $S^n\to\mathbb{Z}$ Are Constant ($n\ge 1$)}

Since $\mathbb{Z}$ is discrete, each singleton $\{k\}\subset\mathbb{Z}$ is open.
A continuous map from a connected space $S^n$ to a discrete space must have
connected image, hence the image consists of only one point.  
Thus any map
\[
f:S^n\to\mathbb{Z},\quad n\ge1
\]
is constant.

\subsection{Computation of $\pi_n(\mathbb{Z})$}

If we fix the basepoint $k_0\in\mathbb{Z}$, the only based map
$S^n\to\mathbb{Z}$ is the constant map $f(x)\equiv k_0$.  
Hence, for $n\ge1$,
\[
\pi_{n}(\mathbb{Z},k_0)=0.
\]

For $n=0$, the path components of $\mathbb{Z}$ are just its points, so
\[
\pi_0(\mathbb{Z})\cong\mathbb{Z}.
\]

\subsection{Summary}

\[
\boxed{
\pi_0(\mathbb{Z})=\mathbb{Z},\qquad
\pi_{n\ge1}(\mathbb{Z})=0.
}
\]

\subsection{Application: Computing $\pi_n(S^1)$ Using the Covering Space}

From the fibration
\[
\mathbb{Z}\longrightarrow \mathbb{R}\longrightarrow S^1,
\]
the long exact sequence gives
\[
\pi_n(S^1)\cong \pi_{n-1}(\mathbb{Z}).
\]
Using our calculation of $\pi_{n-1}(\mathbb{Z})$, we obtain the classical result:
\[
\pi_n(S^1)=
\begin{cases}
\mathbb{Z}, & n=1,\\[4pt]
0, & n\ne 1.
\end{cases}
\]

\section{Understanding why $\partial : \mathbb{Z} \to \mathbb{Z}$ must be multiplication by $2$}

Consider the fibration
\[
SO(2)\;\longrightarrow\; SO(3)\;\longrightarrow\; S^{2}.
\]
The long exact sequence in homotopy (for $n=3$ in the book's notation) contains the segment
\[
\pi_2(SO(2)) \longrightarrow \pi_2(SO(3))
   \longrightarrow \pi_2(S^2) \xrightarrow{\;\partial\;}
   \pi_1(SO(2)) \longrightarrow \pi_1(SO(3)) \longrightarrow \pi_1(S^2).
\]

We substitute the known homotopy groups:
\[
\pi_2(SO(2)) = 0,\quad
\pi_2(S^2) = \mathbb{Z},\quad
\pi_1(SO(2)) = \mathbb{Z},\quad
\pi_1(SO(3)) = \mathbb{Z}_2,\quad
\pi_1(S^2)=0.
\]
Thus the exact sequence becomes
\[
0 \longrightarrow \pi_2(SO(3))
   \longrightarrow \mathbb{Z} \xrightarrow{\;\partial\;}
   \mathbb{Z} \xrightarrow{\;\bmod 2\;}
   \mathbb{Z}_2 \longrightarrow 0.
\]

\subsection{Step 1: Determining the form of $\partial$}

Exactness at $\pi_1(SO(2))=\mathbb{Z}$ means
\[
\mathrm{Im}(\partial)=\ker(\bmod 2).
\]
Since
\[
\ker(\bmod 2)=2\mathbb{Z},
\]
we obtain
\[
\mathrm{Im}(\partial)=2\mathbb{Z}.
\]

Any group homomorphism $\partial : \mathbb{Z}\to \mathbb{Z}$ must have the form
\[
\partial(n)=kn,\qquad k\in\mathbb{Z}.
\]
Its image is $k\mathbb{Z}$.  
To satisfy $\mathrm{Im}(\partial)=2\mathbb{Z}$, the only possibility is
\[
k=\pm2.
\]
Hence
\[
\partial(n)=\pm 2n.
\]
This is the meaning of the sentence in the book:
\begin{quote}
``This forces $\partial : \mathbb{Z}\to\mathbb{Z}$ to be a multiplication by $2$.'' 
\end{quote}

\subsection{Step 2: Computing $\pi_2(SO(3))$}

Exactness at $\pi_2(S^2)=\mathbb{Z}$ implies
\[
\mathrm{Im}\big(\pi_2(SO(3))\longrightarrow\mathbb{Z}\big)
   = \ker(\partial).
\]
Since $\partial(n)=\pm 2n$, its kernel is
\[
\ker(\partial)=\{0\}.
\]
Thus
\[
\mathrm{Im}\big(\pi_2(SO(3))\to\mathbb{Z}\big)=0.
\]
But the map $0\to\pi_2(SO(3))$ at the beginning of the sequence is injective, so the only way
$\pi_2(SO(3))$ can map to $0$ inside $\mathbb{Z}$ is if
\[
\pi_2(SO(3))=0.
\]

So the conclusion is:
\[
\boxed{\pi_2(SO(3))=0.}
\]

\section{Unitarity in 2-2 scattering}
The partial–wave coefficients are defined by projecting the 
$T$–matrix onto two–particle states of definite total momentum 
and total angular momentum,
%
\begin{equation}
f_J(p^2)\;\propto\;
\frac{
\langle\,p , J , \vec m \,|\, \hat T \,|\, p , J , \vec m\,\rangle
}{
\langle\,p , J , \vec m \,|\, p , J , \vec m\,\rangle
}\, .
\label{eq:partialwave-def}
\end{equation}
%
Because $\hat T$ is invariant under translations and under
$SO(1,d{-}1)$, the matrix element in this basis is diagonal in 
$(J,\vec m)$, so the proportionality constant is independent of 
$p^2$ and of $\vec m$.  The result therefore depends only on the 
Lorentz–invariant combination $p^2=s$.

We start from the angular form of the elastic unitarity equation,
%
\begin{equation}
2\,\Im T(s,t(z))
=\int_{-1}^{1}\!dz'\,w(z')\!\int_{-1}^{1}\!dz''\,w(z'')\,
\mathcal P_d(z,z',z'')\,
T(s,t(z'))\,T^*(s,t(z'')),
\label{eq:unitarity-angular}
\end{equation}
%
where
\[
w(z)=(1-z^2)^{\frac{d-4}{2}}.
\]

Next we insert the partial-wave expansion,
%
\begin{equation}
T(s,t(z))=\sum_{L=0}^\infty n^{(d)}_L\, f_L(s)\,P_L^{(d)}(z),
\label{eq:pw-expansion}
\end{equation}
%
and substitute this expression into \eqref{eq:unitarity-angular}.  
At this stage we obtain
%
\begin{align}
2\,\Im T(s,t(z))
&=
\sum_{L,L'} 
n^{(d)}_L n^{(d)}_{L'} f_L(s) f_{L'}^*(s)
\int_{-1}^1\!dz'\,w(z')\,\mathcal P_d(z,z',z'')\,P_L^{(d)}(z')
\nonumber\\
&\qquad\qquad\qquad\times
\int_{-1}^1\!dz''\,w(z'')\,P_{L'}^{(d)}(z'').
\label{eq:unitarity-expanded}
\end{align}

To isolate the coefficient $f_J(s)$ we project both sides of 
\eqref{eq:unitarity-expanded} onto the $J$-th partial wave,
multiplying by
%
\[
\frac{\mathcal N_d}{2}\, w(z)\,P_J^{(d)}(z)
\]
%
and integrating over $z$.  
Using the projection formula
%
\begin{equation}
f_J(s)=\frac{\mathcal N_d}{2}\int_{-1}^1 dz\,
w(z)\,P_J^{(d)}(z)\,T(s,t(z)),
\label{eq:projection}
\end{equation}
%
the left-hand side becomes simply
%
\[
\frac{\mathcal N_d}{2}
\int_{-1}^1 dz\,w(z)P_J^{(d)}(z)\,2\,\Im T(s,t(z))
=2\,\Im f_J(s).
\]

Now we insert the kernel decomposition (eq.~(67))
%
\begin{equation}
\mathcal P_d(z,z',z'')
=\frac12\,\mathcal N_d^2\,w(z')\,w(z'')\,
\sum_{L=0}^\infty n_L^{(d)}\,
P_L^{(d)}(z)\,P_L^{(d)}(z')\,P_L^{(d)}(z''),
\label{eq:kernel-decomposition}
\end{equation}
%
and use the orthogonality relation
%
\begin{equation}
\frac12\int_{-1}^1dz\, w(z)\,P_J^{(d)}(z)\,P_L^{(d)}(z)
=\frac{\delta_{JL}}{\mathcal N_d n_J^{(d)}}.
\label{eq:orthogonality}
\end{equation}

Substituting \eqref{eq:kernel-decomposition} into 
\eqref{eq:unitarity-expanded} and performing the two $z',z''$ integrals,
only the term $L=L'=J$ survives due to \eqref{eq:orthogonality}, giving
%
\[
\frac{\mathcal N_d}{2}\int dz\,w(z)P_J^{(d)}(z)\,(\text{RHS})
=
\frac{(s-4m^2)^{\frac{d-3}{2}}}{\sqrt{s}}
\,|f_J(s)|^2.
\]

Equating both sides yields the elastic partial-wave unitarity condition
%
\begin{equation}
2\,\Im f_J(s)
=
\frac{(s-4m^2)^{\frac{d-3}{2}}}{\sqrt{s}}\,
|f_J(s)|^2,
\label{eq:pw-unitarity}
\end{equation}
%
which is eq.~(68) of the main text.

\section{Solution Structure of $S_i$ from Given Helicity Data}

We are given three helicities
\begin{equation}
h_1,\,h_2,\,h_3\in \tfrac12\mathbb Z,
\qquad 
h_1+h_2+h_3>0,
\end{equation}
three spins $$S_i\ge0$$ (half-integers), and integers $$k_i\ge0$$ satisfying
\begin{equation}\label{eq:basic}
S_i - k_i = h_i ,\qquad i=1,2,3.
\end{equation}
We also impose the constraint
\begin{equation}\label{eq:sumk}
k_1 + k_2 + k_3 \;\le\; 2 S_{\min},
\qquad 
S_{\min}:=\min(S_1,S_2,S_3).
\end{equation}

\paragraph{Elementary implications}\leavevmode\\

From \eqref{eq:basic} and $k_i\ge0$,
\begin{equation}
S_i = h_i + k_i \quad\Rightarrow\quad S_i \ge h_i.
\end{equation}
Hence every spin satisfies the effective lower bound
\begin{equation}\label{eq:Si-lower}
S_i \ge \max(0,h_i).
\end{equation}

Let the ordered helicities be 
\begin{equation}
   h_{(1)}\le h_{(2)}\le h_{(3)}.
\end{equation}

Then
\begin{equation}\label{eq:Smin-lower}
S_{\min}
= \min_{i} S_i
\;\ge\;
\min_{i}\max(0,h_i)
=
\max(0,h_{(1)}).
\end{equation}



\paragraph{Rewriting the constraint}\leavevmode\\

Using $k_i=S_i-h_i$ in \eqref{eq:sumk},
\begin{equation}
k_1+k_2+k_3
= (S_1+S_2+S_3)-(h_1+h_2+h_3)
\le 2 S_{\min}.
\end{equation}

From $S_i\ge S_{\min}$, we have
\begin{equation}
   k_i=S_i-h_i\ge S_{\min}-h_i
\end{equation}
and at the same time $k_i\ge0$, so we obtain
\begin{equation}
   k_i\ge \max\{0,S_{\min}-h_i\}
\end{equation}
Define
\begin{equation}
f(S_{\min}) := \sum_{i=1}^3 \max\{0,\,S_{\min}-h_i\}.
\end{equation}
This quantity is the minimal possible value of $k_1+k_2+k_3$ at fixed $S_{\min}$.  

Thus a necessary and sufficient condition for feasible $k_i$ is
\begin{equation}\label{eq:f-inequality}
f(S_{\min}) \le 2 S_{\min}.
\end{equation}

With ordered helicities,
\begin{equation}
f(S_{\min})=
\begin{cases}
0, & 0\le S_{\min}\le h_{(1)}, \\[4pt]
S_{\min}-h_{(1)}, & h_{(1)}\le S_{\min}\le h_{(2)}, \\[4pt]
2 S_{\min}-(h_{(1)}+h_{(2)}), & h_{(2)}\le S_{\min}\le h_{(3)}, \\[4pt]
3 S_{\min}-(h_1+h_2+h_3), & S_{\min}\ge h_{(3)}.
\end{cases}
\end{equation}

Imposing \eqref{eq:f-inequality} yields:
\begin{itemize}
\item Region I: $$0\le S_{\min}\le h_{(1)}$$  
  Always satisfied.

\item Region II: 
   
      $$h_{(1)}\le S_{\min}\le h_{(2)}$$
   \begin{equation}
      S_{\min}-h_{(1)}\ge 0,\quad S_{\min}-h_{(2)}\le0,\quad S_{\min}-h_{(3)}\le0
   \end{equation}
   So we have
   \begin{equation}
      f(S_{\min})=S_{\min}-h_{(1)}\le 2 S_{\min}
      \quad\Rightarrow\quad
      S_{\min}\ge -h_{(1)}.
   \end{equation}
  If $h_{(1)}<0$, it will give us a non-trival lower bound.

\item Region III: $$h_{(2)}\le S_{\min}\le h_{(3)}$$  
   \begin{equation}
      S_{\min}-h_{(1)}\ge 0,\quad S_{\min}-h_{(2)}\ge0,\quad S_{\min}-h_{(3)}\le0
   \end{equation}
   So we have 
   \begin{equation}
      f(S_{\min})=2S_{\min} - (h_{(1)}+h_{(2)}) \le 2 S_{\min}
      \quad\Rightarrow\quad
      h_{(1)}+h_{(2)}\ge 0.
   \end{equation}

\item Region IV: $$S_{\min}\ge h_{(3)}$$  
  \begin{equation}
  3 S_{\min}-(h_1+h_2+h_3)\le 2 S_{\min}
  \quad\Rightarrow\quad
  S_{\min}\le h_1+h_2+h_3.
  \end{equation}
\end{itemize}

Combining \eqref{eq:Smin-lower} with the former constraints, a solution exists iff
\begin{equation}\label{eq:existence}
h_{(1)} + h_{(2)} \ge 0,
\end{equation}
and the interval
\begin{equation}
S_{\min} \in 
\Bigl[\,
\max\{0,h_{(1)}\},
\;h_1+h_2+h_3
\Bigr]
\end{equation}
is nonempty.

Since $$h_1+h_2+h_3>0,$$ the upper bound is always positive.

Thus \eqref{eq:existence} is the essential obstruction that rules out forbidden helicity configurations.

\vspace*{1em}
Whenever a valid $S_{\min}$ exists, the spins are reconstructed by
\begin{equation}
S_i = h_i + k_i,
\qquad
k_i\in\mathbb Z_{\ge0},
\end{equation}
with
\begin{equation}
k_i \ge \max(0,\,S_{\min}-h_i),
\qquad
k_1+k_2+k_3 \le 2 S_{\min}.
\end{equation}

Because both $$S_{\min}$$ and $$k_1+k_2+k_3$$ are bounded, only finitely many triples $$(S_1,S_2,S_3)$$ are possible for specific helicities.

\subsection{A general lower bound valid for all solutions for $h_1<0,h_{2,3}\ge 0$}
We do not assume which $S_i$ equals $S_{\min}$.  We only use the relations
\begin{equation}
S_i = h_i + k_i, \qquad k_i \ge 0,
\end{equation}
and the definition of the minimal spin
\begin{equation}
S_i \ge S_{\min}.
\end{equation}
From this inequality we immediately obtain
\begin{equation}
S_{\min} - h_i \;\le\; S_i - h_i = k_i,
\end{equation}
and therefore
\begin{equation}
k_i \;\ge\; S_{\min} - h_i.
\end{equation}
Combining with $k_i \ge 0$ gives the unified inequality
\begin{equation}
k_i \;\ge\; \max\{0,\, S_{\min}-h_i\},
\qquad i=1,2,3.
\end{equation}
Summing these three inequalities yields
\begin{equation}
k_1 + k_2 + k_3 
\;\ge\; 
\sum_{i=1}^3 \max\{0,\, S_{\min}-h_i\}.
\end{equation}

Now consider the case of exactly one negative helicity and two positive helicities.
After reordering,
\begin{equation}
h_1 < 0 < h_2 \le h_3.
\end{equation}
Since each $S_i \ge 0$, we necessarily have
\begin{equation}
S_{\min} \ge 0.
\end{equation}

We determine the signs of the terms in the previous inequality:
\begin{itemize}
    \item For $i=1$: since $h_1<0$ and $S_{\min}\ge 0$, we have
    \begin{equation}
    \max\bigl(0, S_{\min}-h_1\bigr)
    = S_{\min}-h_1
    > 0.
    \end{equation}

    \item For $i=2,3$: since $h_2, h_3 > 0$, we only need the trivial bounds
    \begin{equation}
    \max\bigl(0, S_{\min}-h_2\bigr) \ge 0, 
    \qquad
    \max\bigl(0, S_{\min}-h_3\bigr) \ge 0.
    \end{equation}
\end{itemize}

Therefore,
\begin{equation}
k_1 + k_2 + k_3
\;\ge\;
(S_{\min}-h_1) + 0 + 0
=
S_{\min} - h_1.
\end{equation}

Combining this with the fundamental inequality
\begin{equation}
k_1 + k_2 + k_3 \le 2 S_{\min},
\end{equation}
we obtain the chain
\begin{equation}
S_{\min}-h_1 \;\le\; k_1+k_2+k_3 \;\le\; 2S_{\min}
\quad\Longrightarrow\quad
S_{\min}-h_1 \le 2 S_{\min}.
\end{equation}

Rearranging gives the universal lower bound
\begin{equation}
-h_1 \le S_{\min}
\quad\Longrightarrow\quad
S_{\min} \ge |h_1|.
\end{equation}

Since $S_1 \ge S_{\min}$ for all solutions, we also have
\begin{equation}
S_1 \ge S_{\min} \ge |h_1|.
\end{equation}

Thus we have established the following conclusion:

\begin{equation}
\boxed{
\text{For any admissible solution, we necessarily have } 
S_1 \ge |h_1|.
}
\end{equation}

This bound required no assumption about which spin equals $S_{\min}$;
it is a universal constraint following only from the defining inequalities.

\paragraph{Existence of a solution saturating the lower bound}\mbox{}\\
Assume in addition the necessary helicity condition
\begin{equation}
h_1 + h_2 \ge 0 
\qquad\Longleftrightarrow\qquad
h_2 \ge |h_1|,
\end{equation}
which is required for the existence of any solution.

We now construct an explicit solution saturating the inequality $S_1 \ge |h_1|$.
Define
\begin{equation}
S_1 = |h_1|,\qquad
S_2 = h_2,\qquad
S_3 = h_3.
\end{equation}
Using $S_i = h_i + k_i$ we obtain the corresponding integers
\begin{equation}
k_1 = S_1 - h_1 = |h_1| - h_1 = 2|h_1|,
\qquad
k_2 = 0,
\qquad
k_3 = 0.
\end{equation}

Since $h_2 \ge |h_1|$ and $h_3 \ge h_2$, we have
\begin{equation}
S_2 = h_2 \ge |h_1|, 
\qquad
S_3 = h_3 \ge h_2 \ge |h_1|,
\end{equation}
so that in this configuration
\begin{equation}
S_{\min} = S_1 = |h_1|.
\end{equation}

Finally,
\begin{equation}
k_1 + k_2 + k_3 = 2|h_1| = 2S_{\min},
\end{equation}
which saturates the inequality $k_1 + k_2 + k_3 \le 2 S_{\min}$.

Thus the lower bound is sharp: the minimal possible value of $S_1$ is
\begin{equation}
\boxed{
S_1^{\min} = |h_1|.
}
\end{equation}

An explicit solution attaining this minimum is
\begin{equation}
(S_1,S_2,S_3) = \bigl(|h_1|,\,h_2,\,h_3\bigr),
\qquad
(k_1,k_2,k_3) = \bigl(2|h_1|,\,0,\,0\bigr).
\end{equation}

This completes the demonstration that, in the case of one negative helicity and two positive helicities with $h_2 \ge |h_1|$, we not only have the universal bound $S_1 \ge |h_1|$ but also a concrete solution saturating it.
